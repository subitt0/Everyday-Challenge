## 📌 작품 설명 
### 매일매일 챌린지

> Flutter와 Dart 기반의 팀 프로젝트로, 사용자가 매일 새로운 챌린지를 수행하고 기록할 수 있는 웹 애플리케이션입니다. <br>
> 룰렛을 통한 랜덤 챌린지 제공, 포인트로 아이템 구매, 디데이 및 캘린더를 통한 목표 관리 기능을 구현했습니다. <br>
> 또한 Firebase를 활용한 로그인·회원가입 인증, 알림 기능, 업적 및 랭킹 시스템, 커뮤니티 게시판 기능을 포함했습니다. <br>
> 사용자에게 지속적인 동기 부여와 재미를 제공하는 인터랙티브 챌린지 플랫폼을 개발했습니다. <br>


<br><br>
